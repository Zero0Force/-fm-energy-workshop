# FM Energy Workshop

> **Status:** Workshop prototype — exploratory, not production-ready.

## Goal

Predict the next hour's building electricity consumption and display the forecast on a dashboard.

## Planned tools

- **Python** — core language for data handling and the forecasting model
- **Streamlit** — dashboard for viewing the predicted next-hour consumption
- **Neon Postgres** — hosted datastore for electricity readings and forecasts
